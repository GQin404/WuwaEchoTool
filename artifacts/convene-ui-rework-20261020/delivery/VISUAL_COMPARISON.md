## 功能变更

- 普通导入移除额外卡池 ID 与手动直连开关。自动直连，遇网络／CORS或超时才尝试固定本站代理；授权拒绝、限流、无效数据、上游服务故障不通过切换通道重试。
- 自动代理错误区分404路由未部署、405方法不接受、503代理服务不可用，保留上游、授权、格式、超时和存储错误类别。全部池失败不再显示部分成功；已有档案保持原样。
- 程序调用仍可显式指定原连接模式，旧调用的错误兼容保留；普通 UI 使用自动模式。
- 分享 UID 仅隐藏／完整显示，默认隐藏。渲染函数参数 `showUID`，旧 `masked` 参数不再输出任何 UID。预览和下载使用同一 PNG dataURL。
- Windows 简易方式为本地 Logs 文件夹选择，按修改时间尝试 Client.log／debug.log；只读取用户主动选择的文件，不上传、不执行脚本、不改游戏配置和权限。单文件选择为备选；过大文件限制保留。教学视频为明确未提供的预留区。
- 角色图继续按官方角色 ID→既有目录→本地 WebP；无映射或加载失败均提供占位。**仓库没有具体武器立绘目录及可靠资源ID映射**，因此使用重新绘制并明确标记的武器类别 SVG，不冒充某把官方武器。后续可另行接入经过授权及核验的武器图库。
- 全部新增文案简中／繁中／英文。没有改评分公式、存档schema、核心存储或 Echo/Classic业务。
