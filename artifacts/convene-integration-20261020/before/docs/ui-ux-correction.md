# v2.0 可读性与操作层级修正

本轮在第一轮未提交修改上继续精修，没有回退、覆盖其他修改、切换分支、修改 Git 历史、提交或推送。评分公式、角色／声骸目录、存档规则、Classic、导入／导出、备份和分享图脚本均未在本轮改动。

## 主要问题及实际修正

| 区域 | 原有问题 | 本轮变化 |
| --- | --- | --- |
| 顶部角色／配置／评分 | 角色与总分缺少直接的配置关联，观察说明过长 | 评分区增加真实角色及配置名称，显示完整度与 5 槽／Cost 计数；保留主要结论，把已有的判读说明放入原生 details。配置改名后两处名称即时同步，语言切换／选择槽位保留说明展开状态。 |
| 左侧角色 | 操作像普通文本，图片与名称间距偏大，输入及保存难以辨认 | 收紧标题及立绘高度，增加文字尺寸；分享、保存、删除使用清楚的按钮边界与主次颜色，删除继续经过原有确认；配置名表单对齐，方案与空方案文字可读。 |
| 五件声骸 | 12–13px 标签太小，小型笔电／平板隐藏过多比较信息 | 名称 16px、主词条 15px／数值 22px、Cost 14px、有效数量 20px、分数 28–32px；使用共同 grid／subgrid 行轨道，使较长名称换行后五槽主词条、评分仍对齐。保持横向五槽、固定顺序、共同评分尺度、轻量青绿选取及空／缺数据提示。 |
| 单件分析 | 主词条、固定贡献、副词条贡献、整套校正分成多段 | 四组读数集中到一块，桌面四列、窄屏两列；保留声骸名称、Cost、完整度、计分范围及展开后的全量词条／系数／贡献／原因。编辑、比较、收合操作更容易辨认。 |
| 手机 | 字号缩水，操作位于长页末尾，继承桌面 gap 造成多余留白 | 角色信息旁保留小立绘，分享／删除排列在角色信息后；去掉不适用的桌面间距。五槽在独立横向滑动区域保持正常字号，并增加三语滑动提示；整页不水平溢出。详情沿页面向下，手机保留返回列表与焦点恢复。 |
| 角色列表、声骸库、工具及共用标题 | 次要标签与摘要经常降到 12px，新增操作只是下划线 | 共用次要字体基准 14px，提高次要文字对比；新增角色／声骸使用统一的完整按钮边界。库内摘要、工具说明及主要数字保持明显层级，既有搜索、筛选、备份及页签流程保留。 |

桌面重视五件同时比较和四组读数集中显示；手机以正常文字大小、可滑动的五件比较、两列读数和易点击操作为主。没有把五槽改为大量副词条卡片，也没有删去手机需要的返回操作。

## 完整保留的设计与功能

- 深色背景、青绿强调、细线和五件声骸横向展示。
- 原有评分、等级、槽位顺序、主／副词条计算、整套效率校正及其解释。
- 原位分析宿主、候选／比较、空槽补资料、未知模型保护、危险操作确认、会话保留与备份规则。
- 角色主视觉、分享图内容、底部共鸣图示的形状／数量／排列逻辑及 PNG 导出。
- 三语支持；新增两个界面键均同时提供繁中、简中、英文。
