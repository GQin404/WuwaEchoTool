# Register 聲骸庫、搜尋與標題列

本輪維持原有計算、角色資料、草稿與備份格式；沒有變更 Classic 功能、公式、權重、門檻，沒有部署或推送。

## 聲骸庫

- 列表與詳情移除固定最大高度及獨立垂直捲動，桌面保留雙欄，使用頁面主捲軸。
- 詳情經 ResizeObserver 與 viewport resize 檢查實際高度；能完整容納於視窗扣除底部導覽及留白的空間時才啟用 sticky。展開操作或縮小視窗使詳情過高時，回到自然頁面捲動。沒有隱藏 scrollbar。
- 列表以圖片、名稱、Cost、套裝、主詞條、完整度及緊湊副詞條摘要辨識；青綠背景與左線標示選取，收藏為獨立按鈕。
- 詳情依身分、完整度／收藏、主詞條、完整副詞條、編輯／裝備／比較／刪除排列；完整副詞條與操作仍可閱讀。
- 選取及一般收藏操作保留原列表 DOM；依來源與參考角色快取正規化讀數。搜尋、排序、條件、語言或來源變動時才更新列表；收藏篩選啟用時會重新驗證結果。沒有通用評分或新的計算引擎。
- 手機／窄平板使用單欄，開啟詳情後返回操作可回到原列表位置，保留搜尋與条件；長詳情使用頁面捲動。桌面過長的詳情可直接定位閱讀，再返回原列表位置。

## 搜尋盤點及專屬条件

| 介面 | 常駐搜尋 | 收合的進階条件 |
| --- | --- | --- |
| 聲骸庫 | 聲骸名稱 | Cost、套裝、主詞條、完整度、參考角色、原有排序、只顯示收藏 |
| 角色工作台／角色列表 | 角色及配置名稱 | 來源、養成／草稿狀態、原有排序 |
| 原位候選聲骸 | 聲骸名稱 | Cost、套裝、主詞條、完整度、原有／名稱／角色模型貢獻排序、收藏 |
| 比較紀錄／方案管理 | 角色及方案名稱 | 有效、需重比、來源已不存在等原有狀態 |
| 加入裝備的庫存選擇器 | 聲骸名稱 | 原有 Cost 条件；保留可選判定、原因、確認及更新來源 |
| 官方角色導入 | 原有角色搜尋 | 無進階条件；統一搜尋、重設及符合／總數，不加入沒有用途的收合區；批次選取／清除選取仍在原位置 |

候選比較結論本身沒有搜尋清單，沿用候選入口及比較紀錄。分析頁的小型方案連結清單沒有既有筛選，保留連結操作；搜尋由比較紀錄提供。資料管理只有備份／還原控制，沒有清單搜尋。一般角色選擇器、模型條件與表單輸入不改為篩選。

共用 `register-search-ui.js` 僅重新安排既有 DOM 控件，加入原生 details／summary、aria-expanded、aria-controls、鍵盤與 180ms 淡入淡出；尊重 reduced-motion。每個 host 僅註冊一組 UI 事件，以 WeakMap 保留當次展開狀態，不新增資料欄位或儲存格式；各頁的資料來源、篩選與保存處理維持原實作。

進階數量每個非預設條件計一次，排除搜尋；多選有任一非預設項目時計一次；參考角色、非預設排序、收藏均計入。收合不移除控制項、不清除條件；重設恢復全部篩選預設，包括中立參考角色，並保留目前展開狀態及實際角色／方案資料。

## 修改檔案

- 新增 `js/register-search-ui.js`：共用搜尋呈現、條件計數、展開及重設 UI。
- `css/register-operations.css`：沿用原變數，追加共用搜尋、單頁捲動、列表／詳情、手機及 reduced-motion 樣式。
- `js/register-secondary-views.js`：詳情收藏、讀數快取、可略過重建列表的展示入口。
- `js/register-workspace.js`：保留列表 DOM、單一 ResizeObserver、詳情高度判斷、列表返回位置、搜尋元件接入及參考角色重設。
- `js/character-dock.js`、`js/role-candidate-surface.js`、`js/register-import-workbench.js`：接入共用 UI 與原有篩選事件；候選忽略值未變的重複 input/change，避免失焦重入更新。
- `js/i18n-dictionaries.js`：新增三語「進階篩選」，沿用其他現有翻譯。
- `index.html`、`mccost.html`、`mccost-readonly.html`、`register-workspace.html`：載入共用 UI 腳本。
- 新增 `tests/register-search-ui.test.cjs`、`tests/register-search-browser.cjs`；既有兩份操作／整合瀏覽器測試改為先展開進階條件，再操作原控制項，並共用既有 30 配置／200 聲骸測試資料。

## 重跑及人工驗收

```powershell
node --test tests/*.test.cjs
node tests/register-search-browser.cjs
node tests/register-operations-browser.cjs
node tests/register-integration-browser.cjs
node tests/register-import-browser.cjs
node tests/register-tabs-browser.cjs
```

測試使用此環境 Playwright 路徑及 Microsoft Edge，自行開啟並關閉 localhost 服務。OCR 舊腳本需專案服務位於 `http://127.0.0.1:8765`：

```powershell
node artifacts/screenshot-recognition/startup-regression.cjs
node artifacts/screenshot-recognition/save-session-regression.cjs
```

人工請使用獨立測試瀏覽器設定檔／備份副本：

1. 桌面打開聲骸庫，展開条件、選 Cost／收藏／排序，再收合；確認結果仍生效且數量正確，重設後全部清除。
2. 在長列表選取聲骸，切換選取與收藏，確認詳情相符；縮小視窗、展開裝備與刪除區，確認整段可讀且只有頁面捲動。
3. 手機選列表較後面的聲骸，查看完整詳情，再返回；確認位置、搜尋與筛選保留，鍵盤不遮住操作。
4. 依序查看角色列表、候選、比較紀錄及裝備庫存選擇器；以鍵盤或觸控展開、收合、重設，再走編輯／比較／保存／返回。
5. 真實官方服務更新、實拍截圖 OCR、備份與分享下載，使用測試資料核對。

未自動驗證：真實手機／平板硬體軟鍵盤及手勢、Safari／Firefox、真實官方帳號與服務、外部圖片服務可用性。自動化桌面／手機為 Edge viewport 和觸控模擬。已測範圍沒有尚未處理的已知問題；上述項目需實機或外部服務驗收。


## 標題列與返回入口

新增聲骸位於標題右側，與工作台新增角色共用 register-page-heading／dock-create-actions；手機合理換行。聲骸庫、比較紀錄、工具及資料管理不再顯示標題上方的返回原清單；桌面詳情也不顯示冗餘返回。960px 以下的獨立詳情仍保留返回列表，並恢復列表位置與焦點。編輯、新增、OCR、候選比較的返回／取消／關閉仍有實際用途，不刪除共用導覽與三語翻譯。

## 裝備與資料安全

Inspector 的編輯、加入角色、比較、刪除使用原核心。只可加入手動配置，沿用可用位置、五顆及 12 Cost 上限；官方配置維持唯讀。比較帶入角色、位置、原裝備及候選身份，再使用既有 eligibility 和 baseline 校驗。來源已變、已刪、已裝備或身份重複時停止舊結果。資料管理的完整備份與跨頁衝突處理見 [整體流程](register-operations-acceptance.md)。

標題列歷史驗收為四種寬度 × 三語 12 組；保留 results／summary 與目前代表圖。最新全部測試數量以整體驗收及本次實際輸出為準。
