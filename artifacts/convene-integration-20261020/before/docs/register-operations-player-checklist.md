# Register 使用與驗收操作清單

建議先匯出完整備份，再依序操作；以下是手動核對清單，不需要再次逐項批准開發。

1. 進入 Register，切到角色列表。搜尋角色／配置，切換來源、資料與草稿狀態，試用各種排序；核對符合數、總數及重設。切回養成總覽，確認統計沒有跟著列表篩選縮小。
2. 進入同角色的不同配置，修改配置名稱並明確保存。返回列表，核對分頁、搜尋、篩選與排序仍在，配置名稱能辨識。
3. 開啟資料不完整的角色，點問題定位槽位，使用補資料／編輯；官方角色使用更新官方資料。完整角色的最低貢獻位置只是分析入口。
4. 選取聲骸槽位，閱讀主詞條／固定貢獻、副詞條及整套校正，再展開係數。手動編輯並返回，核對原角色與槽位。
5. 打開候選，搜尋並試用 Cost、套裝、主詞條、完整度、收藏及貢獻排序。查看不可選原因，保存一份草稿並比較；返回候選確認篩選仍在，關閉後槽位仍選取。
6. 為方案改名並保存。到比較紀錄搜尋方案，切換狀態，打開同角色的其他方案。切換模型或更新來源後，確認舊差值與有效結論停止顯示；本地採用不改遊戲裝備。
7. 聲骸庫先以中立屬性查看，再選參考角色並依副詞條貢獻排序。使用獨立收藏按鈕，選取詳情、編輯並返回；若篩選不再符合，應有保留選取的提示。
8. 從聲骸庫選角色及替換位置進入比較，再返回原清單。試用搜尋無結果與重設，核對它與真正空庫的提示不同。
9. 修改尚未保存的聲骸或候選，再離開：試用繼續編輯、保留輸入、捨棄。沒有修改時直接離開；語言切換應保留輸入。
10. 匯出／還原完整備份，核對配置名、方案名與收藏；删除草稿應清理採用和名稱引用，角色本身不變。删除來源角色後，紀錄顯示來源不存在，不提供錯誤分析連結。
11. 在手機寬度檢查目前角色、槽位、結論與下一步，詳情返回及底部導覽；以 Tab／Shift+Tab／Space 操作輸入與收藏，核對焦點。最後試用 OCR、分享 PNG、工具及 Classic 切換。

真實官方帳號與手機實機屬外部驗證；本輪結果與截圖見 [完整報告](C:/Users/user/Downloads/WuwaEchoTool/docs/register-operations-acceptance.md)。


## 開啟、保存及備份

直接開啟 index.html 可使用雙入口與一般本機頁面；OCR 上傳須使用 HTTP 本地網站。保持同一協定／主機／port 測試，file://、localhost 與 127.0.0.1 的存檔不能視為同一份。

角色與聲骸存於目前瀏覽器；換機、清除瀏覽資料或大型整理前下載完整本機備份，還原先驗證格式再確認。完整備份包含角色、聲骸、收藏、草稿、本地採用及名稱，不包含登入憑證。

聲骸庫新增可選手動或截圖辨識；OCR 結果逐欄校對，只有明確確認才加入庫存。比較採用只影響工具內方案，不改遊戲裝備。分享可選簡略／詳細並下載 PNG。工具條件修改後先重新計算再閱讀結果；切工具、返回及切語言應保留未提交操作。
