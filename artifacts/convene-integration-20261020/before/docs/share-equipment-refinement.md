# 分享结算与装备详情精修（2026-10-15）

## 实际修改

分享上半部采用三个等高、低对比圆角面板。左侧立绘与双共鸣环保持原比例，名称在立绘下方，共鸣链及真实评分模态使用同一组胶囊；空间不足换行，长名称撑高整个顶部，不压住图片。没有多余身分标题或虚构标签。

中间直接使用原summary.score与原小数格式，数字加大并用700字重、薄荷色和克制光晕/双环强调；不产生新评级、百分比或排名。右侧图表置中，五个编号及真实贡献读数围绕图表，radarData函数完全不改。品牌横幅、左右细线、底部五共鸣符号及五张卡片保留。

简略/详细共用同一顶部代码及比例规则，宽度仍1440/2040像素，PNG原导出路径不变；高度沿用内容自适应，顶部增加空间后普通图高度会适度增加，不宣称像素尺寸完全不变。详细版仍保留主副词条、原有效词条标记与累计数据；未增加技术说明。

装备详情按展示区、主词条卡、副词条列表、操作区、比较区、底部危险区排列。128px图片/名称/Cost/套装居中；主数值突出、副数值右对齐。库没有可靠角色有效性上下文，沿用原数据，不新增有效性判定或品质标签。

编辑和原详情收藏按钮组成一致的44px次要操作；原装备目标选择和确认按钮集中在默认展开的主要操作卡中。默认展开解决目标选择重绘后再次收合的问题，不改装备事务或确认机制。比较角色、位置、资格检查、跳转和原结果均保留。删除仍在底部收合区域，暗红按钮和原确认/事务不变。列表星号仍在卡片内，与详情共用原元数据；新增三语收藏成功反馈，失败沿用原错误提示。

桌面维持1.6:1双栏和实际14px间距；手机保留原返回清单与详情切换。新样式仅限Register装备详情。验收发现旧详情section的padding!important压住新卡片内距，移除该优先级，使16px内距实际生效。
