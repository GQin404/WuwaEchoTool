# Role Register 装备卡片工作台改版

## 本次修改

基于当前工作目录及前两轮未提交修改继续完成。没有回退其他改动、清理已有文件、修改评分、存档或 Classic。当前根目录没有交接包的 `handoff/` 文件夹；以实际源码、当前开发文档及既有交接说明为准。

设计采用深色与青绿、少量暖金，强调角色身份及装备卡片。工作台专属 CSS 已整理为基础、角色、总览、装备、分析、候选／比较与响应式区域，移除旧的无卡片共用轨道及重复覆盖规则；不是在文件末尾继续叠加一轮全量覆盖。

### 桌面

- 容器最大宽度 1440px，260px 角色栏与余下主工作区；区块间距 20px。
- 角色立绘有固定 280px 展示容器；名称、配置和身份信息连续排列，分享为明显青绿主按钮。配置名称／保存保持原语义；删除位于管理区末尾，使用较低视觉权重，仍经过既有确认。
- 整套分数使用 46px 与明确单位，结合配置名称、完整度、装备数量／Cost 和已有观察；不把分数解释为新增的百分比进度，不新增评价等级。
- 五件等宽装备卡片具备独立深色底、细边框、圆角、固定图片区域、名称、Cost、主词条、单件贡献、有效数量与文字状态；青绿边框及淡背景表达选取。
- 卡片使用普通 CSS grid；`alignCards()` 只量测名称与主词条标签的展示高度，在五张卡片间共用最大值。没有 subgrid、存储写入或新的评分计算。长名称可以完整换行，主词条与分数保持对齐。
- 手动及官方入口、三语，在 1280×900 和 1440×900 的正常完整配置下，角色、总分和五张卡片均通过实际首屏边界检查。

### 手机

- 单栏角色摘要采用小立绘、角色／配置名称与身份信息；总分和装备完整度紧接摘要，分享保留明显且易触控的位置。
- 五件卡片使用 132px 横向原生滚动与三语提示，不压缩桌面五栏；主词条详情在下面分析区保留，整页没有横向溢出。
- 配置与角色管理在页面后部的明确 details 入口，初次手机加载默认收合。名称、保存、方案和删除均可发现、操作，不占据过多首屏空间。
- 移除把触控滑动当作“下一槽选择”的自定义处理。滑动只滚动列表，点击／触控卡片才更改选取；原有手机返回、键盘焦点、Escape、未保存保护继续保留。

### 完整分析

选取后立即更新同一个原位分析宿主：先显示身份／位置／单件分数、Cost／完整度／有效数量，再显示主词条、主／固定贡献、副词条贡献和整套校正的 2×2 摘要。

完整副词条明细默认展开，可自行收合；用户收合状态在切槽与语言重绘时保留。保留实际值、模型系数、贡献、计分原因、模型条件、候选与比较等全部现有功能。校正明确保留整套范围，不分摊或推导新分数。语言换行改变上方高度时，按分析区锚点保持阅读位置。
