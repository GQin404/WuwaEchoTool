## 后续修正：普通限定角色的 UP 身份与旧待确认标记

用户进一步明确普通限定角色池规则：安可（1203）、卡卡罗（1301）、鉴心（1405）、维里奈（1503）、凌阳（1104）为歪；其他已识别的五星角色为 UP。实现以稳定资源 ID 判断，不依赖显示名称或当期活动日期能否唯一匹配。选择型、联动、隔离池及无法识别的资源不套此普通池规则，也不反推出不存在的具体活动 ID。

原问题有两层：一是将角色 UP 身份绑定具体公告的日期映射，二是旧 `unknown` 待确认标记优先级过高，会盖掉后续已能确定的小保结果。现在 `unknown` 作为待重算状态；明确人工 win／loss／guarantee 仍优先，原始存档字段和备份标记不被改写。连续 UP 后再中 UP 可判为小保；歪后下一次 UP 为大保底。首段或实际记录缺口后的 UP 显示“中 UP · 大小保待确认”，不把已知 UP 身份显示成整笔未知，也不把不明大小保强算小保胜利。

新增 7 项回归，覆盖常驻五位、无日期映射、旧 unknown 两种存法、明确人工修正、真实缺口、特殊池隔离与分享文字一致。合成复现“凌阳 → 2 抽心 → 5 抽心 → 71 抽心”，结果依次为“歪 → 中 UP · 大保底 → 中 UP · 小保 → 中 UP · 小保”。对应 [桌面截图](standard-roster-history-1440.png)、[手机截图](standard-roster-history-390.png)。原账号没有提供完整文件，仍不能声称已逐笔检查其真实六笔记录；已有本地资料会在分析时自动应用修正，无需重新导入。

评分公式未改，但识别结果改善后，可确认小保数量、覆盖率、限定运和最终称号可能相应变化。历史和角色分享统一调用结果文字助手。识别覆盖说明改称“小保／大保判定覆盖率”，与已知 UP 身份区分。判定规则修订号更新为 `automatic-v4-standard-roster-2026-10-27`，存档版本仍为 1。
