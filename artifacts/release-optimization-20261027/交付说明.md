## 数据逻辑与评分政策

### 识别及样本

- 自动识别需要地区、时间和可唯一确认的卡池身份。同期存在多个卡池且记录只有泛称时，仍保持未知；不会用取得角色的名称或 ID 反推出自己选择了哪个卡池。
- 人工 annotations 优先于旧记录中的人工 result，人工 result 优先于自动推断。人工 unknown 会保留，重新导入、更新映射及重复合并不会静默覆盖。冲突合并保留当前存档的人工判定。
- 首个五星此前的抽数只作为观察下限；只有连续记录中两个五星之间的完整、合法间隔参与出金速度。断档重置自动保证状态。
- 可确认小保胜率 = 命中 /（命中 + 非限定）。保证与未知不进入这个分母。这是可确认样本胜率，不代表全部记录的真实胜率。
- 识别覆盖率 =（命中 + 非限定 + 保证）/ 全部限定角色五星结果。覆盖率、完整间隔数与记录缺口分别呈现。
- 图鉴展开区列出实际权重、全部样本门槛、完整间隔数、相关抽数、四类结果计数、排除记录与原因，以及可追溯的时间和记录 ID。内部识别只用于站内证据，不绘入分享图。

### 合成与授予

出金速度公式保持 `100 × (硬保底 − 完整间隔) / (硬保底 − 1)`，在有效完整间隔间取均值。

| 条件 | 使用维度 | 评价 |
|---|---|---|
| 无记录 | 不计算 | 无记录，中性主题 |
| 未达到 10 个完整间隔或 300 次相关抽取 | 可以显示已有计算分数 | 样本不足，不授予正式等级，中性主题 |
| 达到一般样本门槛，但识别覆盖低于 80% 或小保机会不足 5 次 | 100% 出金运 | 暂定评价；明确当前只评定出金运 |
| 一般样本与识别门槛均达成 | 80% 出金运 + 20% 限定运 | 正式授予，最高阶另检查额外门槛 |
| 数值达到 T8，但不足 30 个完整间隔或 10 次确认小保机会 | 保留实际计算分数和计算等级 | 暂定，不静默降成另一正式等级 |

80% 覆盖与 5 次小保机会集中在 `ConveneCore.RATING_RULES`。它们是本工具的保守产品政策，用于避免少量易识别失败代表整份战绩；不是官方概率、置信区间或全服排名。

- 主要角色资料来源要求仍为库街区；本次未取得可核对的库街区结构化名称表，没有声称经过库街区重新核实，也没有新增或更改技能倍率。
- 心、锁暝及专武映射来自[国际服官方 3.7 版本资讯](https://wutheringwaves.kurogames.com/en/main/news/detail/5529)中图片里的唤取章节，与[官方版本说明](https://wutheringwaves.kurogames.com/en/main/news/detail/5571)交叉核对。补录原因是旧抓取器只读正文，遗漏了图片中的新角色。

- 国服依据[官方 3.7 版本资讯](https://wutheringwaves.kurogames.com/zh/main/news/detail/5531)的活动日历及[版本说明](https://wutheringwaves.kurogames.com/zh/main/news/detail/5569)单独登记。日历只给日期，因此标注 `datePrecision: day` 并排除两端日期，不借用国际服精确时间。
- 可重用事实保存在 `docs/convene-reviewed-history-facts.json` 和原有国服事实文件，更新脚本会保留它们。官方图片证据见本目录 `official-global-1.jpg`、`official-global-phase2.jpg`、`official-calendar.png`。
- 角色名复用既有 `character-catalog.js`，声骸名复用既有 `screenshot-name-aliases.js`。套装名称采用项目已使用的 Encore 补充源，明确记录于 `docs/register-name-sources.json`，不将补充来源冒充库街区资料。
- 项目套装 ID 是内部 ID，不能直接当游戏套装 ID。显式核对了 37 个内部 ID 的名称映射；例如内部 23 为星构、25 为逆光、32 为冥途，未改写存档中的套装引用。

### 配置、比较及分享

- 同一颗实体可跨配置、跨角色引用；同套配置禁止重复引用。复制配置仍复制引用，不复制独立声骸。
- 编辑前显示共享影响范围；保存时保留原风险确认。卸下、删除配置和删除实体仍使用各自语义。
- 不同 Cost 的原始贡献不作为品质百分比或直接替换建议。比较仍按原有单槽副词条评分、收益/代价和条件判断；条件、模型或来源改变后须重新比较。
- “采用本地草稿”保存到既有比较/本地采用存储，当前配置不自动改变，更不代表更换游戏装备。
- 简略分享最多显示两项有效副词条，按当前角色模型的原始贡献降序；并列使用稳定词条键排序。不具备有效模型时不编造“重要属性”。主词条始终显示。
- 详细分享与下载使用同一画布；原尺寸预览允许在弹窗内放大查看。养成图片文件名不带内部角色 ID；唤取图片不绘制 Token、完整 UID 或内部 server ID。

## 未验证项与限制

1. 本次没有实体手机、系统虚拟键盘或手机下载/分享面板。因此手机结果仅为浏览器视口模拟；没有宣称 Android / iOS 真机通过。
2. 没有使用真实账号 Token 发起官方唤取 API 导入，也没有重算用户提到的三个真实账号。不能断言那些账号的真实胜率应是多少。
3. 没有真实玩家旧版备份样本；已验证现有 schema、既有历史字段兼容测试和独立浏览器中的合成完整备份往返。不会把构造数据称作真实旧备份。
4. Windows / Android / iOS / macOS / Linux / 主机教学没有通过真实游戏与设备逐一实测；外部脚本未下载执行。保留来源、固定版本与未验证说明。
5. “冰墩墩”条目正式名和外语名仍待可靠资料；未猜译、未删除原 ID，也未合并到其他声骸。
6. 库街区未取得可核对的结构化名称表。补充名称来源已显式登记；没有将补充资料静默宣称为官方图鉴结论。
7. 未对所有主题进行屏幕阅读器及专业色彩对比认证。已检查基本语义、焦点、减少动态效果与实际视口溢出。

## 数据格式与迁移

- 完整备份仍为 `wuwa-register-backup` version 1；唤取备份 version 1 不变；沿用现有多配置模型，不增加新迁移。
- 不保存派生运势分数、等级或主题；每次从当前账号记录计算。
- 新增 `wuwa.convene.selectedAccount.v1` 仅保存最后使用账号偏好，不改账号归属或记录身份。
- 已有人工字段、显式 unknown 与有效昵称在验证/合并时保留。显示名称变化不重建角色或声骸。
- 规则修订标识更新为 `automatic-v3-overall-eight-tier-2026-10-27`；角色养成评分模型与公式未更改。
- 完整还原继续覆盖核心、草稿、采用、名称与收藏；唤取继续追加合并。同 ID 内容冲突在写入前拒绝。
