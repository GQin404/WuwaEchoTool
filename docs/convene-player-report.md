# WuwaEchoTool 唤取记录自动分析重构交付报告

日期：2026-10-21。本文为本次交付的当前说明，旧版 `docs/convene*.md` 属于历史设计记录，涉及人工标记的旧说明不再适用。

## 已实现的行为

玩家只需要导入。历史记录和数据管理中的结果选择、初始保底输入及写入事件全部移除；自动计算不读取 `records.result`、`annotations`、`initialStates`、`initialAnchors` 或旧分析参数。备份校验、重复导入和合并仍保存这些原始兼容字段。没有清除账号、UID、记录、声骸或分享设置。

角色页默认展示取得战绩：次数、完整五星间隔、平均/最快/最慢、已知间隔合计、角色速度分数与称号。UP 身份未知不会使这些有效间隔失效。R0～R6 保留为默认折叠的独立可选比较。页面主徽章、角色图鉴和普通角色分享统一读取角色取得评分，目标分享仍使用目标模型。

新增四星或以上保底进度、13 类默认查询、26 项成就、两套六阶称号的完整评语与中性徽章。Windows、Android、iOS 指南已按公开来源重写。旧声骸评分公式、角色权重、多配置数据模型未修改。

## 保底与评分计算

### 记录连续性

一次成功返回的完整池快照建立连续区间；重叠快照合并。没有重叠的两次快照不推定中间没有漏抽。每个区间开头的第一个五星只展示已保存抽数下限，直到观察到下一次五星才能得到准确间隔。同秒批次不会因为名称相同而去重。

五星间隔为同一保底组、同一连续区间内两个五星的记录位置差。它不依赖 UP 判定。普通重复卡池超过已核对硬保底的间隔不计入评分并提示记录问题。新手池为一次性池，不把关闭后的空白当成下一轮保底。

当前五星进度在最后一个连续区间已有五星锚点时为精确值；否则显示“已记录 N 抽”。即使只有下限，也可给出 `H−N` 的最多剩余值，例如连续保存 73 抽未出金，最多剩 7 抽；不会把进度伪装成精确的 73。到达/超过规则边界的异常记录不继续给出合法剩余值。

四星计数明确标为“四星或以上”：在同一连续区间内每个四星或五星后重置；无锚点时显示下限。普通、新手与已核对联动/回响规则采用公告的 10 次四星或以上保证。保底组或保存区间变化会重置锚点，超过规则边界会提示。

### 自动大小保

普通限定角色：已核对常驻五星可确认歪出，下一次状态变为保证；已唯一识别的活动 UP 在小保状态下为小保命中、在保证状态下为大保命中。最早可见 UP 的前态未知时，不伪造小保命中，但可以确认其后回到小保状态。保证状态下再次出现不相容的常驻五星属于证据冲突，不计胜率。

初始未知、UP 身份未明、历史缺口或选择型活动未保存选择对象时，只保守处理 UP 指标。五星间隔、角色次数、当前可靠保底及取得速度仍可用。已确认的常驻歪出不需要玩家补填历史。

普通限定武器五星必为所选 UP，不计角色 50/50；其保底与角色池独立。选择型周年活动的候选名单不视为同时 UP。回响活动官方公告只证明回响类型内部继承，不能与普通限定混算。

### 两套评分与目标比较

整体沿用原公式：每个有效完整间隔的速度分 `100×(H−N)/(H−1)`；有可确认小保机会时为 80% 速度 + 20% 小保命中比例，没有机会时只用速度，不按 0% 命中处理。正式整体称号要求至少 10 个有效间隔与 300 条适用记录；最高阶另要求 30 个间隔和 10 次可确认机会。

角色取得评分只平均该角色有效完整间隔的速度分，至少 3 个有效间隔授予称号；不足时保留可计算分数与完整中性徽章。它衡量取得前的五星速度，不等于“为这个角色花了多少抽”。已知区间合计只加总准确间隔，不把未知首段加进去。

整体和角色取得均使用未舍入分数映射：深渊/漫长守候 `[0,20)`，逆风 `[20,40)`，平稳/同行 `[40,70)`，幸运/相契 `[70,85)`，星运/眷恋 `[85,95)`，天命 `[95,100]`。三语言称号、评语与图鉴区间同步。

可选 R0～R6 比较仍表示 1～7 次历史取得目标，不推断游戏账号实际共鸣链。展示已取得次数、还需次数、可确认投入与分析状态。目标投入只使用已确认活动和完整链路；区间效率使用明确锚点并拒绝无法归属目标的其他五星。原目标公式 `100×(1−(P−K)/(160K−K))` 保留，160 是比较基准；该分数不会覆盖默认角色取得评分。

## 历史卡池资料覆盖

本次读取了 155 份国际服官方唤取/维护公告；生成 162 条国际服活动条目，另以独立国服公告补充 6 条，共 168 条：普通限定角色 81、普通限定武器 81、联动角色 2、联动武器 2、回响角色 1、回响武器 1。普通条目中包含复刻及选择型周年活动；共 6 条选择型条目均标注需要选择对象，不能凭取得角色反推。

国际服公告时间范围为 2024-06-06 至已公布的 2026-11-11；结束于未来的活动属于已公告排期，并非声称已经运行完成。国服目前补充今汐/时和岁稔、相里要/诸方玄枢、椿/裁春的独立公告窗口；不是全量国服活动库。读取到的国服版本内容说明大多只列新角色和获取渠道，没有完整卡池起止窗口，因此未直接复制国际服日期冒充国服历史。国服通用概率公示已核对，地址见来源清单。

每条包含稳定 ID、类型、UP 对象或候选对象、有效时间、地区、继承组、规则版本与官方来源。未知国际服服务器使用窗口内部日期保守匹配，首末日期不靠不透明服务器 ID 猜测 UTC 偏移；原有已核对 Asia 窗口保持支持。国服与国际服不会互相套用 UP 窗口。

同期开多池时先检查活动标签等身份。公开响应校验器提供的是 `cardPoolType/resourceId/qualityLevel/name/time/isSorted`，未发现可靠逐抽活动 ID 或玩家所选 UP 字段；`sourceId` 仅用于同秒顺序，不当作活动 ID。URL 的 gacha_id 也没有被证明是每条历史记录所属活动。无法唯一定位时保留候选，不按所获角色“倒推选择”。

### 查询类别与联动核对

公开适配器目前列出：1 限定角色、2 限定武器、3/4 常驻、5 新手、6 新手自选、7 赠礼、8/9 新航、10/11 联动、12/13 回响。这是从参考站公开适配器核实的查询枚举，未使用真实玩家凭证访问官方接口验证。本站已经补齐 1～13 查询；不支持的类型会按池报告失败，不损坏成功记录。

官方 4836/4852/4844/4860 公告证明：露西与丽贝卡同属 At Dream's Edge；角色用 Dreamcatcher Tide、武器用 Shadowforge Tide；保底计数仅同活动同类型继承，角色/武器之间不互通，也不继承普通限定。均有 10 次四星或以上保证。武器五星必为对应 UP。

这些公告没有公开联动五星硬保底数、角色完整 50/50 数值规则；不假设 80、不授予该部分硬保底分数。已能确认同活动的连续记录仍计算真实五星间隔、当前已保存进度与四星计数。未来其他联动不直接套用本活动规则。来源只给出泛称或跨活动身份不明时继续隔离。

## 成就与视觉

26 项：抽数里程碑 1/100/500/1000/3000；五星次数 1/10/30/100；1 抽五星、10 抽以内、5 次 20 抽以内、3 次 75 抽以上、一次硬保底；连续三次低抽数、两次双星相邻、歪出后保证；5/10 位四星或五星角色、5/10 种四星或五星武器；同角色七次取得；联动五星；五星武器；30 次四星；六个保存月份。

## 平台教程核对

### Windows

提供用户指定的固定版本 WuWa Tracker 命令与源码入口，明确是第三方，不宣称本站原创。不执行该远程脚本。已阅读固定版本源码：检查注册表/安装路径，选择较新 Client.log/debug.log，支持 XOR 解码，显示并复制网址；包含 Engine.ini 禁日志检测、确认后备份/改写、ACL 拒绝规则修复及所有者/管理员权限修改分支；管理员重启分支改为获取 710dffa 版本，故外层固定版本不代表所有分支都固定同一哈希。

教程顺序为启动游戏、打开历史、开启 Windows PowerShell、查看源码与复制命令、自行选择执行及理解权限提示、取得 URL、贴回本站。原本站离线日志解析和本地 PowerShell 读取器作为独立备用方案保留，未混用远程命令。已经过模拟日志解析/脚本测试；没有对真实游戏安装目录执行第三方脚本。

### Android

核对参考站当前的 Airplane / Client.log / Ascent 三种入口，以及其链接的作者教程。Ascent 2.1.6 支持声明为 Android 11+，需 Wi-Fi/热点、开发者选项及无线调试配对；配对后 Connect，再打开游戏历史，在 Ascent 复制捕获 URL。解释 ADB 读日志的权限与结束后忘记配对、关闭调试。未要求向本站上传全设备日志。

飞行模式错误页能否显示完整 URL，以及 Client.log 可读性会随 WebView、Android 版本和厂商变化，指南明确其兼容性未实机验证；失败提供同账号 Windows 方案。没有把开发者选项或降低系统权限检查写成普遍必须步骤。

### iOS

实际观看参考站链接的 Chario 视频关键步骤，确认使用 Stream、HTTPS Sniffing、本机 VPN、安装/信任 CA、打开游戏历史及请求列表。参考站明确证书下载用 Safari。指南说明完整信任的设置路径、HTTPS 解密的范围与风险、捕获后停止 VPN/撤销信任/移除对应证书描述文件，不建议删除学校/工作管理配置。

原视频末端向 Tracker 导入的是 API JSON；本站 URL 导入与其不同。指南明确本站需复制 aki-gm-resources 历史网页请求的完整 URL，不能把 API JSON 粘贴成 URL。这条本站适配路径和当前 iOS 版本尚未实机验证，未宣称成功；不愿安装证书时可使用同账号 Windows 获取链接。
