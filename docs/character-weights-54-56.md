纯模型为 `scripts/new-character-model.cjs`，其中 `missingCharacterFacts` 保存本次使用的十级系数。`scripts/missing-character-report.cjs` 输出全部配置并生成文末表格。执行同步脚本后，网页直接使用同一个模型，不依赖在线接口。

通用参考：基础攻击1000、总攻击2500、暴击80%、暴伤280%、普通增伤乘区2，同级目标。普通包按自身攻击、增伤、暴击期望与最终增幅计算，随后正则化到五类占比；词条权重按参考点的边际收益计算。未指定武器、套装、队友或装备声骸主动技能，不凭空加入这些伤害。表格中的“其他”既可能是可吃攻击双暴的变奏／声骸技能，也可能是不能吃这些词条的骇破包，两者分开计分。

### 骇破参考口径

图鉴明确给出“偏谐系数”倍率，但角色条目没有给出足以重建实战结果的完整等级基数、敌人和触发轴。本模型采用**10000偏谐参考基数**，仅作为明确的评估点，不宣称这是官方公布的90级常数。转换为模型等效预算时乘 `10000/(2500×2×2.44)`，2.44为80%暴击、280%暴伤的普通暴击期望，用于对齐两种量纲。

每轮假定一次骇破响应；露西协议中的运动失能按实际Ram预算另计。骇破包单列“其他”，不套用普通攻击、面板双暴、四类专项增伤或普通属性增伤；共鸣链明确指定的骇破倍率、最终增幅和防御忽视仍按相应规则处理。该口径包含对特殊伤害乘区的建模假设，实际占比对敌人机制、响应次数及参考基数敏感，不能用于声称某个固定配队的精确伤害。

## 露西

默认“暗网深潜·完整循环”，另有“网络行者·速切”。算法压缩是同一循环内状态，不拆成两个互不完整的角色。

十级关键倍率：有效载荷突进与追加共100.25%，脉冲干扰308.60%，死锁258.47%，压缩普攻一至四段合计455.21%，双线程167.05%，多线程基础238.60%，网络行者覆写894.65%，暗网深潜覆写1789.29%，集群入侵79.53%，运动失能911.83%偏谐系数，响应1367.75%偏谐系数，变奏138.28%。

**伤害分类：**普通准备普攻归普攻；有效载荷／脉冲干扰归技能；死锁、压缩普攻、双线程、多线程、两种解放的覆写、集群入侵全部归重击；运动失能与响应归独立骇破包；变奏归其他。不因按键叫“共鸣解放”就给解放增伤占比。

两种循环都计一次变奏、一次有效载荷和脉冲、准备普攻第二第三段及重击第二段。完整循环额外计一次死锁、一套压缩普攻、一次双线程、一次持SQL多线程，最后用暗网深潜覆写。速切不进入算法压缩，以网络行者覆写收尾，不重复加入压缩连段。假设协议选择在增伤覆盖内完成，完整循环的压缩段及覆写享受65%衍射增伤。此覆盖与传输协议／根权限是否足够需要后续录像校准。

协议选择示例固定为优先运动失能：零／一链24 Ram施放4次运动失能；二链起32 Ram施放5次运动失能，再用余下2点施放一次集群入侵。没有同时免费加入义体故障、突破协议等耗Ram选项；不同协议分配需要另算，不能视为全部策略的唯一最优解。

| 链 | 应用方式 |
|---|---|
| 1 | 变奏后的自身攻击加20%基础攻击，参考按14秒覆盖；免打断与击杀转移机制不凭空增加单目标伤害。 |
| 2 | Ram由24变32；脉冲后新增450%攻击的重击包；持SQL多线程由基础×3.7改为×6.6，不将“提升560%”误当×5.6。 |
| 3 | 覆写倍率×1.5且仅该包暴伤+100%；运动失能与响应系数×1.65。 |
| 4 | 偏移触发后普通属性增伤+20%，按覆盖评估；骇破包不套普通属性词条。 |
| 5 | 生存效果，不虚构输出提升；本例与四链占比／词条权重相同。 |
| 6 | 假设目标已有偏移／干涉，重击最终×1.4、骇破×1.6；不把停滞延长折算成额外攻击次数。 |

默认不计击杀后网络后门，不把丽贝卡机枪塔强化伤害归到露西本人。临时无偏移、无法响应或程序选择不同的场景不能直接套本表。

## 丽贝卡

默认“快速协奏·提前收枪”，另有“机枪爆发·持续”和“机枪爆发·首轮”。猎手／铁胆通过技能互换，默认一个循环内都使用，不作为两个互斥角色。

十级关键倍率：猎手普攻三段279.02%，铁胆三段432.99%，两种战术闪避分别84.50%／101.40%，两种强化重击分别397.66%／278.34%，切换技能每次236.60%，本例入场变奏270.40%，机枪三档每发24.30%／48.60%／72.90%，大烟花636.20%，骇破响应2358.89%偏谐系数。

**伤害分类：**本例常态攻击、强化重击和解放机枪射击都归普攻；切换技能归技能；大烟花归解放；变奏／机枪塔／独立骇破包归其他。循环未使用吃枪子或普通铁胆重击，因此重击占比为0，不代表所有招式都没有真正的重击分类。

循环包含一次变奏、两次切换技能、猎手与铁胆各一套普攻及一次战术闪避、各一次强化重击、一次大烟花和一次延奏机枪塔。爆发情景机枪采用5／5／10发，对应过载 `5×2+5×4+10×6=90`；速切仅第一档打一发后主动提前大烟花。不是在打满90过载后又额外加一轮射击。

持续循环假设12秒手感火热效果及固有两层10%攻击覆盖；解放额外团队20%攻击也计入自身，因此参考总攻击2900。首轮三链前的猎手／铁胆普通攻击分别只吃本形态暴伤／忽防；三链起变奏提供120手感火热，可按双形态效果覆盖。该参考不是逐秒叠层器，早段攻击加成覆盖按相同评估点近似。

| 链 | 应用方式 |
|---|---|
| 1 | 只将图鉴指定的普通连段及战术闪避倍率×1.5；不错误提高强化重击、大烟花或机枪射击倍率。 |
| 2 | 普通属性增伤+20%、全伤害最终×1.15；不把脱战手感回复加速当作额外永久伤害。 |
| 3 | 解放机枪和大烟花倍率×1.6；变奏提供120手感火热，首轮允许更早获得双形态加成。 |
| 4 | 双形态的30%暴伤与15%忽防分别强化为48%与24%，不是各加60个百分点。忽防按同级、无其他减防 `2/(2-ignore)` 处理。 |
| 5 | 自身普攻增伤+20%，只作用普攻包。 |
| 6 | 所有来源的普攻增伤数值放大到1.4倍，因此普攻词条的边际收益也乘1.4；每次强化重击另加900%攻击的普攻包。首轮脱战4秒赠120狂热额外计一次猎手强化重击及一次900%包；持续不重复获得这次赠送。生存回血不加伤害。 |

机枪塔表中只给每发2.5%与14秒持续时间，没有完整射频：本例按每秒一发共14发估算，归丽贝卡本人，不将下一位角色的重击／全伤害加深计入本人。未选露西队友，不默认添加机枪塔250%倍率强化。骇破响应额外按固有30点谐度破坏增幅及参考基础10点合计40点，即×1.4；这也是明确的参考覆盖假设。

## 洛瑟菈

提供“声骸·持续／首轮”和“霜渐·持续／首轮”。默认声骸持续。两种模态分别计分，不能把声骸技能伤害错归共鸣技能。

每轮：变奏97.42%获得100印象，追光连同前置聚焦588.76%再获得50印象，共150点冲洗三张照片；解放142.74%，追忆普攻第一第二段226.01%，第三段52.12%×8，依次消耗三张照片，各触发一次285.48%的遗忘，最后断舍离848.07%。不同时重复加入普通变奏与硬切变奏。

声骸模态的解放起手、遗忘、断舍离归“其他”中的**声骸技能伤害包**，仍吃自身攻击／双暴／冷凝增伤；追忆普攻始终归普攻。霜渐模态前述转换包改归普攻，两模态的技能归类都不是共鸣解放伤害。

声骸模态有追光25%声骸增伤和解放30%声骸增伤；霜渐解放提供30%普攻增伤。持续声骸假设前轮4层变焦在30秒时限内维持，相关声骸包暴伤+40%；首轮解放起手1层，随后三次遗忘按2／3／4层，收尾4层。追光一链暴击在前置聚焦之后开始，普通参考暴率80%加到100%，不让已满暴击的包继续获得暴击率词条收益。

| 链 | 应用方式 |
|---|---|
| 1 | 追光起及之后的包暴击+20%，10秒覆盖；聚焦提速与抗打断不凭空增加连段次数。 |
| 2 | 声骸模态额外声骸增伤+40%；霜渐80%效应加深保留为团队效应机制，不伪造直接攻击收益。 |
| 3 | 断舍离倍率×2。 |
| 4 | 三次遗忘依次攻击+100／200／300，收尾+300；第三段8次普攻按3／3／2次分布在三层区间，近似交错覆盖。准备技能不提前吃满三层。 |
| 5 | 三次遗忘倍率各×1.5，不扩大到断舍离。 |
| 6 | 三次消耗照片后满3层铭记，断舍离额外伤害按×7，与三链倍率×2分别处理；此处依描述将“伤害提升”视为独立乘区。击杀后脱战回印象不重复算入持续循环。 |

**霜渐统计边界：本分支统计本人直接伤害。** 胶卷会让队友附加霜渐时额外触发，最终伤害还依赖队友归属、霜渐／霜冻转换、层数和触发轴；本次不把队友异常总量归给洛瑟菈，也没有为未明确归属的霜渐伤害捏造固定预算。因此霜渐表不是整队伤害占比，二链的团队效应提升不会反映为直接伤害词条分数的提高。独立冷凝抗性降低8%按共同覆盖处理，在直接伤害的相对比例中抵消。

洛瑟菈共鸣能量上限为0，解放不耗能量；共鸣效率评分与参考充能均为0，不能沿用125能量角色的充能权重。

## 接线、保存与验证

全部配置通过统一 `getRoleScoreConfig` 接入单词条、整套、主词条和导入重算。默认值及未知旧玩法回退到每位角色的首项；不改角色ID、名称别名或图片路径。新玩法也加入比较草稿允许的模型条件，切换玩法后不错误复用另一玩法的比较结果。

新版界面的新玩法名称提供简体中文、繁体中文、英文；旧版玩法控件和规则页继续简体中文。新代码注释及本开发文档以简体中文为主。

参考配置：通用双暴、百分比／固定攻击；露西以重击副词条、丽贝卡以普攻副词条作参考；洛瑟菈声骸模态不虚构“声骸伤害”可刷副词条，以额外固定攻击作参照。参考组合作为约100分的比较口径，不宣称最优配装。露西／丽贝卡充能沿用一般输出角色额外40%封顶启发式，未根据真实能量球验证。

重算命令：

- `node scripts/sync-new-character-model.cjs`
- `node scripts/missing-character-report.cjs --write-docs`
- `node tests/missing-character-scoring.test.cjs`
- `node tests/new-character-scoring.test.cjs`（本批全部182组配置）
- `node tests/missing-character-browser.cjs`（三语、手动／导入、保存重载及旧版简体控件）
