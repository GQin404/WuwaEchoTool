## 界面与保存

手动声骸页与导入声骸页均提供对应角色的设置：

- 爱弥斯：震谐／聚爆。旧存档默认震谐。
- 达妮娅：聚爆／集谐。旧存档默认聚爆。
- 西格莉卡：声骸以外额外共鸣效率，默认0%，不包含基础100%。武器等提供的充能需要手动填写。

设置保存在每个角色的 damageMode / extraEnergy 字段，切换立即重算并保存。模态与战斗中的人形／机兵、布景／幻灭形态不同；默认循环已经包含形态切换，不用拆成多名角色。导入角色重新打开时会重新计算，避免沿用旧分数。高链仍使用同一副词条参考套，以保持比较口径。

## 可重算模型

模型位于 scripts/character-chain-model.cjs。运行 node scripts/character-chain-model.cjs 可以查看结果；测试同时核对模型与网页静态配置。

按以下流程推导：为零链循环分配相对伤害预算；按每条链的效果只修改命中的伤害包；叠加前置链效果；按五种增伤分类汇总后除以总预算。预算不是技能倍率。下述特殊转换明确标注为模型假设。

固定参考面板：暴击80%、含既有被动的暴伤280%、总攻击为基础攻击的2.5倍、普通增伤乘区2倍。同级敌人。未逐一套入武器、队友覆盖时间、敌人数量、抗性或帧数。

攻击、属性伤害、双暴的权重按伤害包的相对边际收益调整，零链默认模态与原规则对齐。普通包的暴击期望为1 + 0.8 × (暴伤倍率 − 1)。异常／震谐等特殊包单列，不能获取普通攻击、双暴、四类增伤的分数；六链固定双暴只提高该包预算，不提高面板暴击词条的收益。依然是原线性评分的近似扩展，不是完整伤害模拟器。

### 爱弥斯（49）

默认持续循环、原固有技能已由合适队友叠满；不计脱战首轮额外重击和击杀连锁。零链预算为普攻8、普通技能2、蓄力重击15、光翼共奏25、过载5、终结25、变奏／装备声骸等5、震谐15。聚爆将特殊伤害预算改为25，总量重新归一化。蓄力重击、光翼共奏均归解放，因此重击增伤占比为0。

1链只给即刻响应重击增加300%暴伤；2链光翼共奏翻倍，震谐按10段逐段叠层平均1.7倍，聚爆按30层轨迹的倍率公式重算；3链分别强化终结与过载。原被动已满，因此不重复叠加60%暴伤和25%终结加深。4链提高属性增伤；5链侧重击杀与生存，在无击杀、无死亡循环中与4链数值相同；6链解放包乘1.4，轨迹假定积满60层，特殊包的固定双暴期望为2.4倍。

轨迹30／60层是满层情景，未满层、对群震谐随机分摊、聚爆连锁以及首轮会改变结果。聚爆2链采用(1+4+0.15×30)/(1+2+0.10×30)；6链继续用60层重算。六链固定双暴绝不作为角色声骸面板输入。

### 西格莉卡（51）

零链预算：普攻5、未强化技能1、强化普攻／技能16、符语24、回路终结36、解放12、其他6。声骸技能包占88%，与其他剩余伤害分开保存。所有声骸技能仍显示在五分类的“其他”里，不错误映射到技能或解放增伤。

1链强化16预算的包；2链强化回路终结；3链以持续循环满4层天赋相对零链满2层处理，符语与回路乘2.2/1.6；4链全体攻击增益不改变伤害占比，但降低攻击词条相对权重；5链强化解放；6链再给符语／回路加深与无视防御，按同级敌人、无其他减防取2/1.7防御修正。六链共同30%增幅在占比中抵消。首轮天赋尚未叠满不适用这个持续循环估值。

新增充能分段计分：总效率125%开始转化、150%封顶。声骸外额外效率为x、声骸效率为e时，声骸贡献的有效转化量为 clamp(x+e−25,0,25) − clamp(x−25,0,25)。额外积点为有效转化量×2×声骸技能占比×当前属性增伤权重，按整套计算一次。基础充能启发式在总150%截断。输入武器充能会同步改变参考分母，不能把武器赠送部分算成声骸收益。

该公式是把游戏转化机制映射到原评分积点的近似，未实时模拟该增伤对各伤害包占比的反馈。转化积分显示在整套总分，单件分数相加可能与总分不同。

### 绯雪（52）

固定两层雪锈、持续循环；不把二链脱战三点归刃当成每轮都有。零链预算：普攻2、技能7、预求身普通连段15、居合20、强化重击16、见心／归刃25、变奏5、装备声骸2、异常8。除常世身普攻和普通技能外，上述直接输出主体归解放。

1链强化预求身连段，并将异常附加次数假定由21次增至23次；2链强化居合；3链强化两种重击，异常预算乘(203.77+102+488)/(203.77+102)；4链普通增伤按2.0变2.2；5链技能倍率提高；6链普通直接伤害暴伤加40%，见心／归刃另加500%。固定两层雪锈，未计三层效果及队友额外附加频率。21次附加和各包预算均为待实测校准假设。

### 达妮娅（53）

固定粒子充足、蚀域持续命中，循环内切换两形态。零链预算：布景普攻5、泡泡技能3、放逐技能12、粒子转换攻击15、蚀域20、布景解放10、幻灭解放30、变奏／装备声骸5。粒子转换攻击与蚀域归解放。

1链增加暴伤；2链放逐倍率提升，聚爆模态另增加属性增伤；3链幻灭解放强化，并将一发满黯核泡泡转为解放，+1200%倍率按“零链有效循环6000%攻击”的假设折算为20预算；协奏增加后，补普攻预算5降至2、粒子攻击15降至10。4链蚀域持续频率按4/3计，5链强化布景解放；6链提高攻击与属性增伤，聚爆模态额外加入一次引爆，预算假定12；集谐不加此包。

未把协奏能量当作共鸣能量降低充能需求；沿用规则2的充能权重。队友聚爆伤害不全部归给达妮娅，零链常规聚爆归属和集谐对队友的辅助价值不单独量化。集谐响应的共同增幅不改变直接伤害分类；不模拟敌人失谐窗口。6000%与12预算是可调整估算，不是图鉴数值。

## 参考分母

共同43311主词条：暴击22%、属伤30%×2、攻击18%×2，固定攻击150+100+100。每件副词条含暴击10.5%、暴伤21%、大攻击11.6%。剩余十槽：

- 爱弥斯／绯雪：小攻击60×5、解放11.6%×5。
- 西格莉卡：小攻击60×5、充能12.4%×3、普攻11.6%×2，另计充能转化。
- 达妮娅：小攻击60×2、充能12.4%×3、解放11.6%×5。

每链、每模态均按各自权重重新计算分母，参考套约100分；逐词条舍入存在小误差。参考套不是全局最优配装，表中的0也不表示该属性无用。规则页列出全部42组链数／模态组合及分母。

## 验证和维护范围

node tests/character-chain-scoring.test.cjs 检查42组配置、独立链数据、参考套归一化、模态切换、固定双暴、充能阈值与导入格式计分。界面选项不覆盖账号数据；本地存档保留。露西及之后角色不在本次参数范围。

后续用固定队伍、武器、链数与循环录像的伤害分类统计替换预算，可从同一模型重算数据。当前完成的是0–6链和双模态的机制估算配置，不意味着所有实战组合的精确模拟已完成。
