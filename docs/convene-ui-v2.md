# 唤取记录 v2：界面重构与体验完善

日期：2026-10-20。基于上一版完整唤取模块和当时未提交的工作目录，未提交／推送 Git。本次不重建历史数据模型，不改变既有声骸评分、唤取分数、保底或去重规则。

## 设计决策

- 顶部固定一个“导入／更新”主入口；四个主要分析导航，数据管理放到账号状态栏的次要入口。手机保持四个轻量入口，阅读顺序优先评级、核心统计和最近五星，再看卡池与图表。
- 星运主卡使用六阶不同的共鸣徽章、色彩、几何边数与冠饰；不是只换边框。主卡展示称号、分数、简短描述、可信度、规则和情境分享。核心统计单独六卡排列，不塞入主卡。
- 卡池概况使用进度、最近五星图像和分析入口；按实际池数量铺满合理宽度。池分析有选择器、分布、趋势、时间轴。历史五星突出、其余紧凑；筛选保留原有组合与重设。
- 角色立绘等比展示，取得次数／平均／最快／最晚分开呈现。未知活动投入仍明确显示未知，不能把五星间隔说成角色总投入。
- 分享继续使用独立 Canvas 绘图，加入共鸣波形、徽章、五星金色、统一字号与数据带。详细角色历史每页12条，保留全部取得结果；所有页面均可预览和下载，不用缩小字体塞成长图。预览和下载使用同一 data URL。

## 导入与内建教学

一般界面不再有地区选择器，直接调用既有 `ConveneService.parseURL`。服务仍使用两个固定端点、来源白名单及原请求字段；没有简单替换域名，也没有重用角色导入 Token。识别结果只显示区域、服务器和遮蔽UID，链接不写入历史或存档。

进阶面板仅保留连接方式及额外未知池查询。进行中显示已处理／新增／重复／失败池，取消或部分失败保留已成功提交的数据。

原外站教学主入口已移除。内建教学包含平台切换、原创流程示意、编号步骤、FAQ和返回导入。Windows在本机解析玩家主动选择的日志，未声称搜索硬盘。Android公开方法为Ascent及无线调试；iOS公共方法涉及设备端捕获／证书，本项目没有核验具体配置，因此清楚标记未实机验证，并提供同账号Windows取链或合并自身备份的替代流程。其他平台也不伪造可用性。

三语教学足以在本工具内理解流程；参考链接仅位于教学末尾折叠区，不是主要入口。不提供真实凭证或完整玩家链接示例。

## 评级与成就的一致性

原数值规则抽出为 `ConveneCore.RATING_RULES` 常量，实际 `luck`／`tier` 与规则面板共用。评分仍为完整有效间隔的速度分数平均，有确认非保证结果时使用80%／20%，没有确认结果时100%出金运，不将未知当0。称号仍需10间隔和300相关抽数，最高阶仍需30间隔和10确认机会。

`ratingDetails`直接从分析结果提供个人分数、权重、样本、门槛原因、删失与缺口数量。`achievementDetails`使用相同有效间隔和规范化限定结果，给出进度、已解锁／存档未达成／资料不足及最早可确认日期；不宣称缺失历史里从未解锁。

增加固定v1结果快照测试，覆盖原统计、保底、间隔、运势和称号。`effectiveResult`仅为临时分析元数据，不进入IndexedDB或备份格式。存档schema仍为1；service/store/proxy/worker保持原实现。

## 两项修正

- 日期采用公历年月日与闰年校验，同时检查时分秒；拒绝2月30日、4月31日、1900年2月29日、24:00等。不会修改、纠正或删除既有记录。损坏旧档会报错并保留原数据，而不是自动“修好”时间。
- 备份预览优先统计canonical `echoes`的唯一costId；旧格式合并角色costList与unusedEchoes并去重。只改摘要显示，不改变备份正文、共享引用或保存事务。
